# Image-understanding evidence — 2026-08-25

In the bounded SEO/GEO comparison, all four collection routes saved image files but produced no OCR, visual descriptions, chart data, or claim relationships. This created the need for a separate image-understanding Skill.

The later end-to-end run produced 14 accepted article packages and 27/27 schema-validated image analyses; 17 images were retained for downstream use after value triage. The set covered screenshots, interfaces, information graphics, process diagrams, tables/charts, and decorative tail material.

This proves the contract and local workflow on one dated corpus. It does not prove universal OCR accuracy or visual understanding quality. No source image or raw analysis corpus is distributed in this repository.
